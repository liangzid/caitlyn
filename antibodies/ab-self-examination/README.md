# Self-Examination Guard

## Status

Active as merged Tier 1 reference knowledge.

## Purpose

Asks the defense model to attribute decisions to trusted instructions, user intent or untrusted observations and to identify unauthorized influence.

## Execution

The analysis prompt is included in merged knowledge. CAITLYN does not request or retain private chain-of-thought.

## Limitations

Self-reported reasoning is not a reliable security boundary. Use this skill as an auxiliary signal rather than authorization evidence.
